# University Student Management System

## 1. Project Description

The University Student Management System is a
software application designed to help a university
manage student information and academic records.

## 2. Problem Statement

The university currently uses manual processes
and disconnected systems to manage student records.
This results in delays, duplication and inefficient
information management.

## 3. Project Objectives

- Register new students.
- Manage student information.
- Manage course enrolments.
- Record examination results.
- Generate student reports.

## 4. Main Users

- System Administrator
- Admissions Officer
- Lecturer
- Student

## 5. Technologies

- HTML
- CSS
- JavaScript
- Python or PHP
- MySQL
- Git
- GitHub
